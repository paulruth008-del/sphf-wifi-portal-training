# Development Track

The development track focuses on the learner-facing portal pages.

## What you will practice

- reading and editing HTML pages
- applying shared styles
- understanding page-to-page flow
- improving accessibility and clarity
- identifying where back-end or router placeholders would connect

## Files in this track

- `portal/login.html`
- `portal/status.html`
- `portal/logout.html`
- `portal/error.html`
- `portal/alogin.html`
- `portal/redirect.html`
- `tasks.md`

## Suggested approach

1. Start with the login page
2. Trace how a user moves through the portal states
3. Improve labeling, messaging, and accessibility
4. Compare your work with the examples folder
