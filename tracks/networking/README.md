# Networking Track

The networking track explains how a captive portal relates to network design and access control.

## What you will practice

- mapping the user traffic path
- understanding pre-authentication restrictions
- planning logical segmentation
- discussing dependencies between network and portal behavior

## Files in this track

- `topology.md`
- `vlan-plan.md`
- `tasks.md`

## Key idea

A captive portal is not only a web page. It depends on routing, DNS behavior, gateway policy, and device movement through different access states.
