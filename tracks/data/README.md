# Data Track

The data track helps learners think about what information a captive portal system needs and what it should avoid collecting.

## What you will practice

- identifying entities and fields
- reading a simple SQL schema
- working with fake CSV data
- discussing retention, privacy, and minimal collection

## Files in this track

- `schema/sample-schema.sql`
- `sample-data/demo-members.csv`
- `tasks.md`

## Key reminder

All records in this track are fictional and for training use only.
