# Cybersecurity Tasks

## Beginner

- Review the login form and identify three security questions to ask
- Find all placeholders that should never hold real secrets
- Compare the user portal and admin placeholder pages
- Use the checklist to note one strength and one weakness

## Intermediate

- Expand the threat model with one new threat actor and mitigation
- Suggest safer behavior for redirects after login
- Add a privacy-focused warning to one training page
- Propose a server-side validation checklist for a real implementation

## Stretch ideas

- Write a simple abuse-case table
- Rank the top three risks by impact and likelihood
- Create a secure deployment readiness checklist
