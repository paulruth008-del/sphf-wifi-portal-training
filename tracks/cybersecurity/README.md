# Cybersecurity Track

The cybersecurity track focuses on risks, safeguards, and review habits for a simplified captive portal system.

## What you will practice

- spotting trust boundaries
- reviewing form and session risks
- identifying sensitive data exposure
- mapping mitigations to realistic threats

## Files in this track

- `security-checklist.md`
- `threat-model.md`
- `tasks.md`

## Important note

This content is for defensive education and system hardening awareness.
