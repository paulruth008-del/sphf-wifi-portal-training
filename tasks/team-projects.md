# Team Projects

These activities are designed for mixed-discipline groups.

## Project 1: Safer login flow

- Development updates the login and error pages
- Data reviews required fields and retention notes
- Cybersecurity reviews misuse cases and redirect risk
- Networking explains how the gateway would enforce the flow

## Project 2: Support-ready portal

- Development improves status messaging
- Data proposes a minimal session record
- Cybersecurity adds an operator checklist
- Networking drafts a support troubleshooting path

## Project 3: Classroom demo day

- Prepare a walkthrough of the full captive portal journey
- Show how each track contributed
- Document open questions and real-world gaps
