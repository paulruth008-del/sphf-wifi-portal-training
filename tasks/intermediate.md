# Intermediate Tasks

These tasks are for learners ready to connect decisions across disciplines.

## Suggested sequence

1. Complete one intermediate task in your main track
2. Review one file from a second track
3. Document a dependency between the two
4. Present one proposed improvement and its trade-offs

## Intermediate challenge ideas

- Map portal form fields to the sample schema
- Explain how a redirect decision affects security
- Suggest a network troubleshooting checklist that helps developers too
- Update one page and document how the change affects another discipline
