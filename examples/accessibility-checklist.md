# Accessibility Checklist

Use this checklist while reviewing portal pages.

- [ ] Each page has one clear main heading
- [ ] Form controls have visible labels
- [ ] Keyboard users can reach all controls
- [ ] Error or status messages are understandable
- [ ] Color is not the only way information is conveyed
- [ ] Link and button text is descriptive
- [ ] Pages work at small screen sizes
- [ ] Decorative images are handled appropriately
- [ ] Screen reader users can understand page flow
