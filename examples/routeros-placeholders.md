# RouterOS Placeholders

This file explains example placeholders learners may see in captive portal integrations.

## Common placeholder categories

- login target URL
- redirect destination URL
- session identifier
- user/device identifier
- network policy result
- logout target

## Training note

Different captive portal platforms inject different variables. Keep these placeholders clearly labeled and never treat them as real production values unless your deployment documentation defines them.

## Classroom exercise

Pick one HTML page in `tracks/development/portal/` and annotate where a router, gateway, or policy engine might inject values.
