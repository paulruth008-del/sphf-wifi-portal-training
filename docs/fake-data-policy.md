# Fake Data Policy

This repository uses **fake/demo data only**.

## Rules

- Do not add real names tied to real members, staff, or visitors
- Do not include real phone numbers, email addresses, account IDs, or credentials
- Do not include real device MAC addresses, IP addresses tied to real environments, or production configuration secrets
- Clearly label all demonstration records as fake

## Acceptable examples

- invented sample member records
- placeholder URLs and tokens
- non-routable example network references used for teaching
- synthetic sessions or test states

## Why this matters

Training repositories are often copied, forked, projected in classrooms, or shared publicly. Using fake data reduces privacy, safety, and compliance risks.

## If you are unsure

Do not commit the data until it has been replaced with an obviously fictional example.
