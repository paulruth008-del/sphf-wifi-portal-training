# Build Roadmap

This roadmap shows how to move through the project in a simple and practical way.

## Stage 1: Understand the portal

Goal: understand what the system is supposed to do.

Tasks:
- read the shared docs
- look at the portal pages
- understand the user flow from login to logout
- identify placeholders and fake data

Output:
- a clear understanding of the project structure
- a simple explanation of how the portal works

## Stage 2: Improve the portal pages

Goal: make the portal clearer and easier to use.

Tasks:
- improve headings and instructions
- fix confusing text
- improve layout and styling
- review accessibility basics

Output:
- cleaner portal pages
- better user experience

## Stage 3: Connect the flow

Goal: make the pages feel like one working system.

Tasks:
- improve links between pages
- define what happens after form submission
- explain status, redirect, and error states
- document the expected form fields

Output:
- a clearer portal journey
- better understanding of page-to-page flow

## Stage 4: Add data thinking

Goal: understand what information the portal needs.

Tasks:
- review the sample schema
- review the fake sample data
- map form fields to data fields
- decide what data is necessary and what should be avoided

Output:
- a simple data model for the portal
- better understanding of privacy and data collection

## Stage 5: Review security

Goal: spot risks and improve the design.

Tasks:
- review the login form
- identify possible misuse or weak points
- discuss input validation
- review redirect and admin access concerns

Output:
- a basic threat-aware portal design
- a list of improvements for safer behaviour

## Stage 6: Understand the network side

Goal: see how the portal depends on the network.

Tasks:
- study the topology and VLAN notes
- explain pre-auth and post-auth access
- discuss what the router or gateway would do
- identify what services are needed for the flow to work

Output:
- a clearer picture of how the portal fits into the Wi‑Fi system

## Stage 7: Bring it together

Goal: combine the work from all tracks into one simple project.

Tasks:
- review all track outputs
- update the portal based on shared feedback
- agree on the final simplified flow
- prepare a short team demo

Output:
- a simplified portal system built by the attendees
- a shared understanding of how the full system could work
