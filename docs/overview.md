# Overview

The SPHF Wi‑Fi Portal Training Lab is a shared project for understanding how a community Wi‑Fi captive portal system can be planned, built, reviewed, and explained.

## What learners explore

Learners work with the same training project from different angles:

- portal page development
- sample data design
- security review
- network design and segmentation

## Core scenario

A community site offers Wi‑Fi access to visitors or members. Before broader access is granted, users are redirected to a captive portal where they can:

- view a welcome/login page
- submit basic identifying information
- see connection status
- log out or be redirected
- receive an error message if something goes wrong

This repo models that workflow in a simplified way so learners can study responsibilities across disciplines.

## What this lab is not

This repository is **not** a production-ready captive portal implementation. It is a training environment used to:

- understand components and handoffs
- practice front-end and documentation work
- discuss data handling decisions
- identify security and network risks

## How to use this repo

- Read the docs for shared context
- Choose a track that matches your role or interest
- Complete tasks at beginner or intermediate level
- Collaborate on cross-discipline team exercises
