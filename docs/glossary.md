# Glossary

## Captive portal
A web page or flow that appears before a user receives broader network access.

## Redirect
Sending a user from one request or page to another location, often into the portal flow.

## Session
A short-lived record of a user's interaction or access state.

## VLAN
A virtual local area network used to separate groups of devices or traffic.

## Access control
Rules that decide what a user or device can reach.

## Placeholder
A stand-in value, URL, token, or configuration item that must be replaced in a real deployment.

## Fake data
Invented, non-real information used only for demonstrations or training.

## Threat model
A structured way to think about what could go wrong, who might cause it, and how to reduce risk.
