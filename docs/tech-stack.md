# Tech Stack

This training repository keeps the stack intentionally simple.

## Included in the repo

- HTML for portal page examples
- CSS for shared styles
- JavaScript for lightweight front-end behavior
- Markdown for documentation and tasks
- SQL for sample schema design
- CSV for demo records

## Conceptual external systems

These are discussed but not fully implemented:

- router or gateway redirect logic
- authentication or policy services
- member database or directory
- network management tooling

## Why the stack is simple

A simple stack makes it easier to:

- teach foundational concepts
- inspect every file directly
- reduce setup time in workshops
- compare design decisions across disciplines
