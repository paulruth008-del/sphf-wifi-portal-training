# Learning Paths

This repository supports several learning paths that can run in parallel.

## Path 1: Development

Focus on:

- HTML page structure
- shared CSS and JavaScript
- form behavior and validation
- usability and accessibility basics

Start with:

- `tracks/development/README.md`
- `tracks/development/tasks.md`

## Path 2: Data

Focus on:

- identifying the data needed by the portal
- separating required fields from optional fields
- creating safe sample records
- discussing retention and privacy concerns

Start with:

- `tracks/data/README.md`
- `tracks/data/tasks.md`

## Path 3: Cybersecurity

Focus on:

- common captive portal risks
- input validation and secure form handling
- secure defaults and minimum data collection
- threat modeling and review habits

Start with:

- `tracks/cybersecurity/README.md`
- `tracks/cybersecurity/tasks.md`

## Path 4: Networking

Focus on:

- how devices reach the captive portal
- VLAN separation and traffic assumptions
- redirect flow and service dependencies

Start with:

- `tracks/networking/README.md`
- `tracks/networking/tasks.md`

## Group learning idea

Assign different groups to different tracks, then compare answers for the same system. This helps learners see how technical decisions in one area affect the others.
