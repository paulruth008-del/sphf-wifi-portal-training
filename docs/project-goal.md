# Project Goal

This training repo is based on the idea behind the SPHF Wi‑Fi portal project.

The bigger project is about creating a community Wi‑Fi captive portal system that can manage access in a more organised and identity-aware way.

For this training, the goal is simpler:

**Build a beginner-friendly version of a Wi‑Fi captive portal system and understand how it works.**

## What that means in practice

As an attendee, your job is to help build a simple portal experience that shows the main parts of the system.

That includes:

- a login page
- a status page
- a logout page
- an error page
- a redirect step
- simple fake data examples
- notes about security and networking decisions

## What you do not need to build

You do not need to build the full production system.

That means you are **not** expected to fully implement:

- real RouterOS setup
- real RADIUS authentication
- real user databases
- real monitoring systems
- production-ready security controls

Instead, you should focus on understanding the purpose of those parts and building a simplified version that is easier to learn from.

## Main learning goal

By the end of the training, you should be able to:

- explain what a captive portal is
- describe how a user moves through the portal
- build or improve portal pages
- understand what data the system needs
- spot important security concerns
- explain how networking affects the portal flow
